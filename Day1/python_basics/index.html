Python 기초 문법변수와 사칙연산 for 중첩 반복문f-string 조건문과 입력random

아래 결과는 파이썬 실습 코드를 따라 브라우저에서 확인할 수 있도록 준비한 예시입니다. 숫자 게임은 이 페이지 안에서 직접 실행됩니다.

1. 변수와 사칙연산

number1 = 100, number2 = 200일 때의 결과

number1 + number2 = 300
number1 - number2 = -100
number1 * number2 = 20000
number1 / number2 = 0.5

2. print로 구구단 출력

2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8

3. 중첩 반복문과 f-string

2단부터 4단까지 1~4를 곱한 결과

2 x 1 = 2    2 x 2 = 4    2 x 3 = 6    2 x 4 = 8
3 x 1 = 3    3 x 2 = 6    3 x 3 = 9    3 x 4 = 12
4 x 1 = 4    4 x 2 = 8    4 x 3 = 12   4 x 4 = 16

반복문을 사용하면 같은 형식의 계산과 출력을 짧은 코드로 만들 수 있습니다.
